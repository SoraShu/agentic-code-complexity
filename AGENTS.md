# Repository instructions

- Do not commit or push unless the user explicitly requests it. A request to edit or organize files is not authorization to commit.
- Benchpress is internal company code and must stay outside this repository. The experiments used Harbor's native Copilot integration; do not add the unused external adapter.
- Keep only code and derived artifacts used by the thesis. Publicly obtainable raw data belong in ignored `work/`, with source URLs or acquisition instructions under `data/`.
- Paper TeX/PDF assets belong to the separate thesis repository. Generate outputs under `work/`.
