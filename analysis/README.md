# Thesis analyses

`figures/` generates the empirical Results figures from final saved predictions.
`cases/` extracts the three failure cases and the evidence used by Appendix B.
Both read final data and write generated files under `work/`; neither executes
agents, calls Judge, reruns repository tests or fits regression models.

Final figure assets and conceptual diagrams belong to the separate thesis
repository. Revision logs, discarded rubric comparisons and intermediate feature
experiments are not part of this directory.
